Each project carries its own team (tag and avatars), because teammates can change between projects of the same course; the course header shows no team. Each project on a course page is a full write-up with five tabs: Overview (pictures and description), How it works (steps and a figure), Results (chart and conditions), Code (an excerpt with a GitHub link) and Report (the PDF). Without JavaScript all five show one after another. The main project also links to its own full page. The step strip appears only when a course's projects form a sequence, as ECE415's do; a course like ECE348 just lists its projects.
